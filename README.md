# DevWorld

Monorepo cu mai multe proiecte independente. Fiecare proiect are propriul folder la rădăcină și e dezvoltat de propria sesiune AI.

| Folder | Proiect | Stare |
|---|---|---|
| [`ipcam/`](ipcam/) | Aplicație pentru camere IP: live, înregistrare, control PTZ, stocare în Google Drive / OneDrive / local. Web, Android, iOS, Windows. | Design |

## Reguli de lucru

- Fiecare sesiune lucrează **doar în folderul proiectului ei**.
- Fișierele de la rădăcină (`README.md`, `CLAUDE.md`, `.github/`) sunt comune. Se modifică doar pentru convenții valabile în tot repo-ul.
- Un proiect nou primește un folder nou și un rând nou în tabelul de mai sus.
