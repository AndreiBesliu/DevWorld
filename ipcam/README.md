# ipcam (nume de lucru)

Aplicație comercială pentru camere IP. Un utilizator își leagă mai multe camere, vede live fiecare cameră, le înregistrează și le controlează (PTZ). Înregistrările se salvează unde alege el: local, Google Drive, OneDrive și alți furnizori. Rulează pe web, Android, iOS și Windows.

„ipcam” e doar numele folderului până alegem numele aplicației.
