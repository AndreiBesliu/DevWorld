# Atelier AI (nume de lucru)

Aplicație web pentru atelierele de tâmplărie și mobilier la comandă. Utilizatorul încarcă o schiță de mână sau un PDF de la arhitect, iar aplicația:

- extrage corpurile de mobilier cu AI;
- calculează lista de piese după regulile de construcție ale atelierului;
- optimizează debitarea pe foi, cu kerf și fibră;
- arată un preview 3D simplu.

Tehnologii: Python (FastAPI) pentru backend și algoritmi, Next.js pentru frontend.

## Stare

**Faza de design.** Specificația MVP e scrisă și așteaptă aprobarea proprietarului. Nu scriem cod de produs până nu sunt aprobate specificația și planul de implementare al etapei.
